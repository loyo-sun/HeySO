## 实现

- LoyoCloud 模式使用 IndexedDB 原子保存已确认快照与有序待同步队列。
- 工作项字段更新、父级调整本地保存成功后立即返回；云端保存异步执行。
- 首次发送前持久化整个请求；丢失响应、刷新恢复与重试使用同一 requestId、headId 和请求体。
- 保留现有 LoyoCloud 后端的幂等处理、版本、权限与业务校验。
- 同步状态独立于 4.5 秒自动消失的 toast，显示未确认操作数量和失败原因。
- 401 保留编辑页面和队列；409/业务拒绝停止自动重试，提供明确核对与处理。
- 关闭详情、浏览器离开、退出或重配连接时提示；只有本地落盘确认后允许保留本地离开。
- 前后端使用按服务地址、用户 ID 派生的不透明 storageScope，阻止旧账号队列写入新账号。
- 浏览器支持 Web Locks 时，同一空间仅一个标签页可编辑，避免并行覆盖队列。

## 范围

持久队列针对已存在的 LoyoCloud 项目文件操作。新建项目和其他存储提供方保持原保存链路，不在缺少上游幂等保证时自动重放。
项目文件内新建工作项可进入队列；新行在云端确认后出现。复杂排序等操作亦以云端确认结果为准。
关闭页面后不保证继续执行；再次打开同一账号与空间恢复。
