# 执行闭环与行布局验证

同一工作项的新执行经人工验收通过后，将更早的待验收执行转为要求修改，系统备注固定为“新任务已执行”。审核意见注明系统自动触发，活动记录保留触发的新执行 ID。只更新旧执行记录，不将已完成工作项重新转为执行中，也不影响父级或其他子任务。

历史文件加载时兼容修复同类未闭环记录；重复加载不会重复追加审核与活动记录。新执行仅要求修改时不触发自动闭环。云端领域规则打包脚本已包含新模块，LoyoCloud 独立部署时须更新此规则包。

工作项行右侧收紧为状态图标、优先级图标、负责人头像和名称、添加按钮；无添加按钮的行保留同宽空位以对齐。悬停整行显示浅灰背景，拖动目标仍使用原有反馈颜色。

验证：本提交范围内 132 项测试及 Cloudflare 构建/部署预检通过；完整本地工作区 133 项测试通过（另含本地 MCP 扩展测试）。隔离本地数据验证新执行已通过、旧执行需修改、系统自动备注、活动追溯、每行图标数量、负责人距添加按钮 12px、悬停背景 rgb(245,245,246)。
