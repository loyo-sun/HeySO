# 待办池列标题筛选验证

- 点击列标题文字打开筛选，独立排序图标在悬停时显示；已排序列常显升序或降序箭头。
- 工具栏仅保留已生效条件与当前工作项数量；配置列入口移到页面标题右侧。
- 工作项支持标题和 ID 搜索，其他分类字段支持多选；多个列条件同时生效。弹窗选项仅来自当前结果。
- 创建和更新时间使用本地时间显示为 YYYY-MM-DD HH:mm:ss，支持精确到秒的时间范围；开始和结束日期使用日期范围。
- 范围包含起止边界；时间终点包含该秒内所有毫秒。结束早于开始时禁止应用。支持仅设置一侧边界。
- 已筛选列文字标红，工具栏条件可单独清除。

验证：130 项测试、生产构建通过。隔离本地数据验证状态多选、负责人组合、选项收窄、工作项搜索、空结果、筛选清除、独立排序、日期范围和同一秒时间范围。修复横向滚动导致浮层意外关闭的问题；页面无控制台错误。现有包体积构建提示仍存在。
