# HS1-57 / HS1-58 清单开发验证

## 交付行为

- **HS1-57**：修正排序图标的悬停与键盘聚焦选择器。旧样式仅匹配显式 `role="columnheader"`，当前 Ant Design 表格使用原生 `th`，因此悬停规则没有生效。现在同时匹配两种表头；当前排序列仍保持图标可见，触屏仍常显。
- **HS1-58**：清单首批渲染 30 行；在表格滚动容器内向下滚动、接近底部时，每次追加 30 行。最后一批按剩余数量显示，并提示全部加载。提供手动「加载更多」作为大视口和辅助操作入口。
- 在全部数据上完成搜索、列筛选与排序后再截取显示批次，不会因尚未显示而漏查工作项。更改搜索、列筛选或排序后重置为首批并回到列表顶部；打开和关闭详情保留已显示批次。
- 通过 memoization 避免单纯追加显示批次时重复筛选、排序；不改变列配置和个人偏好的持久化方式。更新内置清单帮助。

本次优化减少首屏表格 DOM 与单元格渲染负荷。沿用现有工作空间快照与同步机制，**没有新增服务端分页，也不减少工作空间快照的网络传输量**。105 行验证夹具的首次挂载行数从 105 降至 30（减少 71.4%）；未将此数量变化当成首屏时间或网络性能测量。
