# 个人视图与账号同步（HS1-20）

线路、冲刺、看板、清单、发布、报告的筛选和视图选项统一通过 `useViewPreferences` 保存。刷新、页面来回切换和重新打开项目均恢复上次设置；项目/云文件互相隔离。报告显式分享链接优先于个人默认视图。

本地项目保存在当前浏览器；在线项目使用 LoyoCloud 认证账号和云文件保存，可跨设备恢复。浏览器缓存用于即时显示及离线暂存。设备仅提交改动字段，其他设备的不同字段不会被旧快照覆盖；相同字段以最后提交为准。待确认请求使用固定 requestId 重试，不重复写入。同步失败显示可重试提示。

接口为 `/api/view-preferences/:fileId`，由本地/托管代理转发至 LoyoCloud `/api/v1/heyso/files/:id/view-preferences`，不走共享工作项修改通道。云端配置单独存表，不产生项目内容版本或活动。

验证：前端完整测试 192 项通过；云端完整测试 14 项通过；两套独立本地服务、两套 editor 会话和独立浏览器存储进行跨设备恢复检查；六页面刷新检查；账号/文件隔离、断网重试、旧响应保护、字段增量合并、非法输入拒绝、共享数据不变。
